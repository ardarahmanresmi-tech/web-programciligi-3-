4. KULLANILAN FRAMEWORK VE KÜTÜPHANELER

--------------------------------------------------------------------------------

Projenin arkasındaki mimaride gördüğüm ana bileşenler:

- Node.js & Express/NestJS (REST API altyapısı için)

- Next.js (Dokümantasyon ve web sitesi için)

- Redis & BullMQ (Arka planda çalışan kuyruk sistemleri ve worker'lar için)

- PostgreSQL / Supabase (Veri yönetimi için)

- Puppeteer / Playwright (Sayfa içeriklerini işlemek için)



5. PROJENİN AMACI

--------------------------------------------------------------------------------

Firecrawl'ı incelediğimde, herhangi bir web sitesini doğrudan AI modellerinin 

anlayabileceği temiz bir Markdown veya JSON formatına dönüştürmek için tasarlandığını 

gördüm. Sadece tek sayfayı değil, tüm domain'i tarayıp (crawl) içeriği yapay zeka 

ajanlarına (RAG uygulamaları vb.) hazır veri olarak sunan bir API altyapısı sağlıyor.

8. KLASÖR YAPISI

--------------------------------------------------------------------------------

Proje bir Monorepo yapısıyla yönetiliyor, bileşenler güzel ayrıştırılmış:



.

├── apps/                     # Çalıştırılabilir uygulamalar

│   ├── api/                  # Dışarıya sunulan REST API servisleri

│   ├── worker/               # Kuyruktan iş alıp web taraması yapan sistemler

│   └── docs/                 # Web dokümantasyon uygulaması

├── packages/                 # Proje içi SDK'lar ve paylaşılan paketler

│   ├── js-sdk/               # Node/TS için istemci paketi

│   └── python-sdk/           # Python için istemci paketi

├── docker/                   # Kendi sunucunda çalıştırmak (self-host) için yapılandırmalar

├── docker-compose.yml        # Yerel çalışma ortamı kurmak için Docker dosyası

└── README.md                 # Ana proje dokümanı



9. README DOSYASI İNCELEME

--------------------------------------------------------------------------------

Firecrawl'ın README yapısını gayet profesyonel buldum:
