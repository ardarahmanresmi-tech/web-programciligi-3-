4. KULLANILAN FRAMEWORK VE KÜTÜPHANELER

--------------------------------------------------------------------------------

Projeyi incelerken dikkatimi çeken başlıca teknolojiler:

- LangChain / OpenAI SDK (Yapay zeka ajanı karar mekanizmaları için)

- Playwright (Tarayıcıyı otomatik yönetmek ve ekrandan veri okumak için)

- asyncio (Asenkron iş parçacığı yönetimi)

- Pydantic v2 (Veri modelleri ve tip doğrulamaları için)

- uv & Typer (Paket yönetimi ve CLI geliştirmesi için)



5. PROJENİN AMACI

--------------------------------------------------------------------------------

Browser Use, yapay zeka modellerinin (LLM) tıpkı bir insan gibi web tarayıcısını 

kullanabilmesini sağlıyor. Ajanın web sitelerine girmesini, butonlara tıklamasını, 

formları doldurmasını ve istenen görevleri otonom şekilde yapmasını hedefleyen çok 

popüler bir açık kaynak projesi. Kazıma yapmaktan öte, site üzerinde eylem gerçekleştirmeye 

odaklanmış.

--------------------------------------------------------------------------------

Kod mimarisi katmanlara ayrılmış ve okunması oldukça rahat:

├── browser_use/              # Ana Python kütüphanesi
